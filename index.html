📊 Conectar Meta Ads

Veja leads, gastos e performance das suas campanhas em tempo real

Como conectar
1

Criar app no Meta for Developers

Acesse developers.facebook.com → Meus Apps → Criar App → tipo "Negócio". Copie o App ID e o App Secret.

2

Gerar Token de Acesso

No App, adicione o produto Marketing API. Gere um User Token com as permissões: ads_read, leads_retrieval, pages_read_engagement.

3

Configurar no sistema

Cole seu Access Token e o Ad Account ID (formato act_XXXXXXXXX) abaixo. O sistema vai puxar seus leads automaticamente.

4

Selecionar campanhas

Escolha quais campaign_id monitorar. Exemplo: "Instagram — Aptos NH", "Facebook — Casa NH". Leads dessas campanhas entrarão no Kanban automaticamente.

Conectar WhatsApp ao sistema

Quando conectado, mensagens chegam direto nos Atendimentos e leads do WhatsApp entram automaticamente no Kanban. A conexão usa a Evolution API — open source e auto-hospedada.

Como configurar (passo a passo)
1

Contratar uma VPS

Acesse railway.app ou digitalocean.com. Crie um servidor Ubuntu 22.04 com pelo menos 1GB RAM. Custo: ~R$25/mês no Railway.

2

Instalar Evolution API

Conecte via SSH e execute:

curl -fsSL https://evolution-api.com/install.sh | bash
